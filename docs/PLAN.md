# خطة البناء — تطبيق حالة السيارة

**الأدوات:** Expo (React Native) + NativeWind · Supabase (قاعدة بيانات، دخول، ملفات، Edge Functions) · GitHub · لاحقاً: ماي فاتورة، Sentry

**قواعد البناء كله**
- التطبيق يعرض بس اللي سجّله المستخدم — ما فيه بيانات وهمية (إلا وضع "جرّب بدون تسجيل").
- الفلوس بالدينار الكويتي بـ 3 خانات (فلس).
- عربي أولاً + إنجليزي، والاتجاه يتبع اللغة.
- RLS مفعّل على كل جدول من أول يوم.
- لا تثق بالجهاز: أي شي يمس الفلوس أو الصلاحيات يتحقق منه الخادم.
- المفاتيح السرية على الخادم بس (Supabase Secrets)، أبداً في التطبيق.
- الخادم أول، بعدين الشاشة: ما نعرض "انحفظ" إلا لما الخادم يأكد.
